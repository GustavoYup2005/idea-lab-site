# Activate IDEA Lab tracking

The lab's Material Costs workbook already contains the **Team print pricing** tab. Enter a capstone number, member, machine/material, internal or external tier and quantity. The tab looks up the current F26 rate, shows its unit and calculates the material cost and team total. Tick the job-fee box once per job when applicable. Additional materials can be separate lines with the same capstone number. Manual pricing entries work immediately.

## Connect the website

1. Create a private Google spreadsheet for the order queue under the lab account. Keep editor access limited to lab managers. Open Extensions → Apps Script.
2. Copy Code.gs, Rates.gs, Worksheets.gs and PriceEmail.gs into that project. On the setup PC, StaffSetup.local.gs contains the dedicated staff secret and the eight verified source workbook mappings. Run its configureStaffPassword and configureWorkbooks helpers once in the same project. The local setup file is excluded from Git. Alternatively set STAFF_PASSWORD, SOURCE_BOOKS (a JSON map of spreadsheet IDs to machine names), and PRICE_BOOK (Material Costs spreadsheet ID) in Script properties.
3. Run setup as the lab account. It creates or upgrades IDEA Orders and installs edit and submission triggers on each configured response spreadsheet. Existing Forms and their semester response tabs keep their current destinations. Only new submissions receive codes. To add another source, extend SOURCE_BOOKS and rerun setup. The A1 checkout form is for equipment loans. The A1 is reserved for student take-home checkout.
4. Deploy as a Web app, executing as the lab account, accessible to Anyone if campus policy allows. Put the public deployment URL into NEXT_PUBLIC_ORDERS_API_URL in the website's .env.local, then restart the preview or rebuild with npm run build:nau. Update the deployment version after script changes.
5. Test a new submission and one staff manual entry. Both should create an order, reserve a line in Team print pricing and send a code. On the pricing line, select the actual material and tier if the Form did not provide them. Enter the quantity in the displayed unit. Look up the order with the emailed code and submission email to check the member, capstone, status, cost and file links. Drive continues to enforce each file's sharing permissions.
6. Staff manage status and student-visible notes through the queue or directly in IDEA Orders. Trackers show the linked pricing line's print total. Team totals include all priced lines for the capstone. Use the original linked line for an individual tracking cost. The private queue also supports model and secondary material quantities using the bundled F26 snapshot when no linked total is available. The Team print pricing tab reads the live rate card.

The backend recognizes the observed F26 response headers, including combined email/ID fields. Override headers using EMAIL_HEADER and ORDER_FIELDS (JSON keys team, member, files, tier, material) if future Forms change. The capstone field is the Form's Capstone Speedchart. If an email is not recorded, correct the source submission before intake. For a recorded order with a blank Email sent timestamp, fix the email issue and run retryUnsentEmails. Repeated email delivery attempts reuse the original tracking code.

In the staff queue, select a printer and semester to view and edit the original response rows. Refresh the worksheet after someone edits Sheets. A row with a student email can also receive a tracking record. Rows without an email remain available in the worksheet. Worksheet edits do not send email. Use Team print pricing for quantities, materials, tiers and job fees. Linked print totals appear in student tracking. Rerun setup and update the web app deployment after installing Worksheets.gs.

Save the print price in the printer response worksheet’s Cost column, then use Preview price email on the corresponding tracked order. The printer worksheet price takes precedence over a calculated total. Send price confirmation sends to the stored student email and records a signature and delivery timestamp in IDEA Orders. The direct tracking URL defaults to https://ce.nau.edu/me/idealab/orders/ and can be set with TRACKING_URL. Run setup to add the new queue columns and deploy the updated Apps Script version before using this on campus. An unconfirmed delivery should be checked against the lab mailbox before clearing its signature to retry.
